Button Types Showcase

Explore different buttons, their purposes and interactive behaviours.

Buttons are important elements in web applications. They allow users to perform actions, navigate interfaces and interact with different features. Explore the examples below.

1. Primary Button

Purpose: Highlights the main action on a page. Usage: Used for actions such as submitting a form or saving information.

2. Secondary Button

Purpose: Provides an alternative action. Usage: Used for actions such as viewing details or opening another section.

3. Outline Button

Purpose: Provides a less prominent action. Usage: Commonly used for cancel, back or optional actions.

4. Danger Button

Purpose: Represents an important or destructive action. Usage: Used for deleting or removing items after confirmation.

5. Disabled Button

Purpose: Shows an action that is currently unavailable. Usage: Used when required information is missing or an action is restricted.

This button cannot be clicked.

6. Loading Button

Purpose: Indicates that an action is being processed. Usage: Useful during form submission or data loading.

7. Toggle Button

Purpose: Switches between two states. Usage: Used for enabling or disabling settings.

Current state: OFF

8. Counter Button

Purpose: Performs an action that updates a value. Usage: Used for quantity selection, likes or counters.

How Button Workflows Operate

  1. The user identifies the action they want to perform.
  2. The user clicks the appropriate button.
  3. The button triggers an event or function.
  4. The webpage processes the action.
  5. The interface displays the result or updated state.
